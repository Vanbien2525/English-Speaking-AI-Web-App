*Sơ đồ luồng phát triển chuẩn mực: Từ Day 0 dựng móng, Sprint Loop từng tính năng với Stitch & Jules, đến Final Release Audit.*

---

## 🏛️ Triết Lý Kiến Trúc
1. **No Spec -> No Code:** Không bao giờ gõ code khi chưa có Schema PostgreSQL và API Contract tại Day 0.
2. **Interrogate Before Implement:** Luôn để AI chất vấn ngược qua `/grill-me` để tìm góc khuất trước khi làm.
3. **Stitch For Wireframe, Antigravity For Luxury:** Dùng Stitch định hình bố cục chuẩn mực; dùng Antigravity thổi hồn với Spring Physics, `layoutId`, `mix-blend-mode` và tách nhỏ Components (`<MotionCard>`, `<SpotlightContainer>`).
4. **Test Local, Jules Verify Cloud, Human Merges:** Antigravity viết code và test cục bộ; GitHub Jules thẩm định bảo mật độc lập trên Cloud; và **CHÍNH BẠN LÀ NGƯỜI DUY NHẤT BẤM NÚT MERGE PULL REQUEST**.
5. **Clean As You Go:** Xong tính năng là xóa ngay `plan.md` và file nháp; giữ repo luôn gọn nhẹ tối đa.
