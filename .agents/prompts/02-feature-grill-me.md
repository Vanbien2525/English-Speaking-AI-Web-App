# PROMPT 2: Phỏng Vấn Ngược & Bóc Tách Chi Tiết Tính Năng Con (Giai Đoạn 2)

```markdown
/grill-me Tôi muốn bắt đầu triển khai tính năng con: [Tên tính năng, ví dụ: Nhận diện biển số và mở Barie xe vào].

Với vai trò là một Technical Lead & QA Specialist, hãy thực hiện quy trình sau:
1. Đặt cho tôi từ 3 đến 5 câu hỏi phỏng vấn sắc bén về các góc khuất kỹ thuật mang tính sống còn:
   - Tranh chấp dữ liệu & Đồng thời (Concurrency, Race Conditions, PostgreSQL Row-Level Locking).
   - Kịch bản mất kết nối & Khả năng chịu lỗi (Network Timeouts, Hardware Failures, Rollback mechanisms).
   - Cơ chế chống lặp thao tác (Idempotency, Duplicate Requests).
2. Sau khi tôi trả lời, hãy TỰ ĐỘNG TỔNG HỢP toàn bộ thành một bản tài liệu đặc tả kỹ thuật hoàn chỉnh và lưu vào file `.agents/specs/[ten-tinh-nang].spec.md`.

Bản spec bắt buộc có: User Stories, Acceptance Criteria (Given-When-Then), API Endpoints, DTO Schemas và Ma trận mã lỗi HTTP (400, 401, 404, 409, 500).

Sau khi lưu file spec xong, hãy hướng dẫn tôi gõ `/compact` và nhắc tôi bước tiếp theo với Stitch!
```
